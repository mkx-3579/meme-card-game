# Âm thanh

- Âm thanh giao diện: `card-play`, `vote`, `accept`, `reject`, `tick`, `win`, `your-turn` (đuôi `.mp3`, `.ogg` hoặc `.wav`).
  Thiếu file nào thì game tự phát một tiếng "bíp" tổng hợp thay thế.
- Âm thanh riêng từng meme: `meme-<mẫu>.mp3`, ví dụ `meme-stonks.mp3`. Thiếu thì phát tiếng lật bài chung.

Mỗi file thêm vào phải có một dòng trong `ASSETS.md` (test sẽ kiểm tra).
