# Ảnh meme

Thả ảnh mẫu meme (ảnh trống, chưa có chữ) vào đây, đặt tên đúng theo mẫu, ví dụ `drake.jpg`.
Đuôi được nhận: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`. Danh sách tên nằm trong `card_deck.py` (`MEME_TEMPLATES`) và `ASSETS.md`.
Mỗi file thêm vào phải có một dòng trong `ASSETS.md` (test sẽ kiểm tra). Khởi động lại game là ảnh hiện ra.
