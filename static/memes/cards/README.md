# Ảnh lá bài

Thả ảnh meme (jpg, png, webp, gif) vào thư mục này. Mỗi ảnh là một lá bài, hiện nguyên tấm, không in thêm chữ.
Có ít nhất một ảnh ở đây thì game chỉ dùng các ảnh này; thư mục trống thì game dùng bộ lá chữ cũ.
Ảnh trong thư mục này không được đưa lên GitHub (xem .gitignore), nên cập nhật game không xóa ảnh của bạn.
Cần ít nhất khoảng 5 ảnh mỗi người chơi để chia bài thoải mái; ít hơn thì bộ bài sẽ được xáo lại và lặp ảnh.
Mở ván mới là ảnh vừa thêm có hiệu lực.
